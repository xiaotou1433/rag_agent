# 🚀 AI 大模型 RAG 与 Agent 智能体开发学习项目

本仓库是我学习 **「AI 大模型 RAG 与 Agent 智能体开发」** 的实战练习代码，内容从 OpenAI API 基础开始，逐步深入到提示词工程、LangChain 框架、RAG 知识库问答系统以及 Agent 智能体开发，由浅入深、循序渐进。

## 📚 内容结构

| 目录 | 阶段 | 主要内容 |
|------|------|----------|
| [P1_OpenAI库的基础使用](P1_OpenAI库的基础使用) | OpenAI 基础 | API Key 使用、模型调用、流式输出、历史消息记忆 |
| [P2_提示词优化](P2_提示词优化) | 提示词工程 | JSON 使用、金融文本分类/信息抽取/匹配判断等优化案例 |
| [P3_LangChainRAG开发](P3_LangChainRAG开发) | LangChain + RAG | 通义千问/Ollama 调用、模板、解析器、会话记忆、文档加载、向量检索 |
| [P4_RAG项目案例](P4_RAG项目案例) | 综合项目 | 完整的 RAG 知识库问答应用（含文件上传、问答界面） |
| [P5_Agent智能体](P5_Agent智能体) | Agent 开发 | Agent 初体验、流式输出、ReAct 案例、中间件 |
